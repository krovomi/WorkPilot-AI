# F170 · Venv Python sans interpréteur jamais reconstruit, erreur « Unhandled error » sur toutes les pages Python

- **Sévérité** haute · **trouvé par** Leub (2026-11-08), génération de la Feuille de route puis
  Débogueur d'agent en échec.
- **Preuve** (avant) : `venvExists()` teste `existsSync(bin/python)`, qui suit le lien et répond
  faux pour un lien mort ; `createVenv()` relance `python -m venv` sans `--clear`, qui répond 0 en
  laissant le lien mort (reproduit avec CPython 3.13) ; `installDeps()` fait alors
  `this.emit("error", "Python not found in virtual environment")` sans écouteur, d'où
  ERR_UNHANDLED_ERROR attrapé par `_doInitialize`.
- **Correction** : `python-env-manager.ts` (`fail()`, `createUsableVenv()`, `interpreterRuns()`,
  `createVenv(clear)`) ; tests `src/main/__tests__/python-env-manager-venv-repair.test.ts`.
- Même PR : des « ) » parasites dans la barre des phases de la Feuille de route
  (`RoadmapGenerationProgress.tsx`, test `RoadmapGenerationProgress.render.test.tsx`).
