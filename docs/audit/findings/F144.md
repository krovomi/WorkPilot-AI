# F144 · Collaboration d'équipe écrite côté interface, sans transport ni serveur

- **Sévérité** moyenne · **trouvé par** le scan de nettoyage demandé par Leub (2026-11-02), qui
  a choisi de brancher la feature plutôt que de la retirer · **corrigé par** la PR « brancher la
  collaboration en mode serveur »
- **Preuve** (avant) : `components/collaboration/` sans aucun import hors de son dossier ;
  `sendMessage` qui ajoutait le message au seul store local ; `initialize` jamais appelé.
- **Correction** : salle de projet dans le serveur WebSocket (`project_room.py`), table
  `team_chat_messages` (migration `0012_team_chat`), salle côté main (`server-team-room.ts`) avec
  contrôle de ce que le serveur envoie, `reconcileEdit` pour les modifications de carte, store et
  composants réécrits, section de réglages.
- **Garde-fou** : `tests/backend/test_team_room.py`,
  `apps/frontend/src/main/__tests__/server-team-room.test.ts`,
  `apps/frontend/src/main/__tests__/server-board-actions.test.ts`,
  `apps/frontend/src/renderer/components/collaboration/__tests__/`.
