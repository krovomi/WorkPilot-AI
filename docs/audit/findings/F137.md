# F137 · Des vues annonçaient un résultat qu'elles ne produisaient pas (approbation lue par personne, historique jamais écrit, « Agent » sans modèle) et Idéation bouclait

- **Sévérité** moyenne · **trouvé par** la revue feature par feature du 1er novembre · **corrigé
  par** le lot R1
- **Preuve** (avant) :
  - `grep -rn APPROVAL_PENDING apps/backend` → aucun résultat ; la vraie approbation est
    `review/state.py` (`review_state.json`).
  - `.workpilot/refinement-histories/` n'était écrit par aucun code ; `spec_refinement/`
    n'était importé que par son runner.
  - `useIdeationAuth` mettait dans les dépendances de son effet une fonction recréée à chaque
    rendu ; le nouveau test compte deux appels ou plus avant la correction, un après.
  - Les runners d'accessibilité, d'i18n, d'onboarding, de notebook et du « bac à sable »
    (`git diff HEAD`) n'appellent aucun client d'agent.
  - Un `\0` littéral à l'octet 5 901 de `task-log-service.ts` : `git diff` affichait
    « Bin 27325 -> 27330 bytes ».
- **Garde-fou** : `SpecApprovalDashboard.test.tsx`, `spec-approval-handlers.test.ts`,
  `useIdeationAuth.test.ts` (appels comptés, fournisseur de la page),
  `tests/test_no_nul_bytes_in_sources.py`.
