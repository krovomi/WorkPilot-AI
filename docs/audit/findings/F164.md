# F164 · Revue de code et Refactoring ne marchaient pas dans l'application et ne lisaient que Python et JS/TS

- **Sévérité** haute · **trouvé par** le lot 2 de la charte UI (2026-11-07), en reprenant les vues
  du groupe Développement.
- **Preuve** (avant) : `CodeReview.tsx` et `RefactoringView.tsx` faisaient
  `fetch(`${import.meta.env?.VITE_BACKEND_URL || ""}/api/...`)` ; `SmellDetector.detect_from_source`
  appelait `ast.parse` sur tout extrait et rendait une liste vide sur une `SyntaxError`.
- **Correction** : `main/ipc-handlers/code-insights-handlers.ts`, `runners/code_insights_runner.py`,
  `agents/refactorer_polyglot.py`, `review/polyglot_rules.py` ; tests
  `tests/test_refactorer_polyglot.py`, `tests/test_code_insights_runner.py`,
  `main/ipc-handlers/__tests__/code-insights-handlers.test.ts`.
- **Reste** : `SessionHistory.tsx` fait encore un `fetch` relatif (lot « Espace de travail » de la
  charte).
