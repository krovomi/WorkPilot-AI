- **Sévérité** basse · **trouvé par** le scan de nettoyage demandé par Leub (2026-11-02)
  · **corrigé par** la PR « nettoyage : code mort du desktop »
- **Preuve** (avant) : `knip` (entrées main, preload, renderer, scripts, tests, e2e) ; pour chaque
  méthode des modules preload, recherche de son nom dans `src/renderer` et `src/shared` : zéro

  `getDecisionLog`, `clearDecisionLog`, `onDecisionLogEntry`. `documentation/` n'était importé
  que par le runner ; `DocumentationView` passe par l'API HTTP.
- **Correction** : handlers, modules preload, types, constantes IPC, service, runner, paquet
  Python et `agents/decision_logger.py` supprimés ; `session.py` ne crée plus le journal.
- **Garde-fou** : `python-feature-services.test.ts` (sept services configurés),
  `tests/agents/test_agents_smoke.py`.
