# F135 · Les fichiers d'instructions coûtaient ~11k tokens par session Claude et n'atteignaient pas les providers de la boucle WorkPilot

- **Sévérité** moyenne · **trouvé par** la demande de Leub du 31 octobre (refonte par provider) ·
  **corrigé par** ce lot
- **Preuve** (avant) : `CLAUDE.md` + ses trois imports = 42 Ko chargés avant la première question ;
  les douze règles critiques écrites deux fois (`AGENTS.md` et `docs/CLAUDE.md`) ;
  `.github/copilot-instructions.md` à 4,3 Ko dont 3,5 Ko de BMAD ; aucun `.gemini/settings.json` ;
  `build_base_system_prompt` sans aucune section du projet.
- **Correction** : voir [`docs/architecture/agent-instructions.md`](../../architecture/agent-instructions.md).
  Des plafonds testés empêchent la dérive (racine Claude ≤ 8 Ko, `AGENTS.md` ≤ 7 Ko, chaîne
  Codex ≤ 32 Kio, `copilot-instructions.md` ≤ 2 Ko).
