# F161 · L'agent de génération de tests n'affichait pas l'analyse et répondait en Python ou TypeScript pour les autres stacks

- **Sévérité** moyenne · **trouvé par** la refonte de l'interface demandée par Leub (2026-11-07).
- **Preuve** (avant) :
  - analyse : `analyzeCoverage` résolvait les gaps sans les stocker, le dialogue lisait
    `result.coverage_gaps` ; aucune étape n'était émise pendant l'analyse ;
  - couverture : `--coverage-target` arrivait au runner et n'entrait pas dans le prompt ;
  - framework : détecteurs par langage enchaînés, premier manifeste gagnant ; C# ne regardait que
    les `.csproj` de la racine ;
  - E2E : repli `dummy.ts`, cible relative non résolue contre le projet ;
  - prompts E2E et TDD : `e2e/test_x.js` pour un projet C# ;
  - TDD : 5 langages dans l'UI, `--language` par défaut `python` pour les bibliothèques ;
  - UI : bordure jaune en dur sur l'E2E, statuts en anglais seulement.
- **Correction** : PR « Test generation studio », tests `tests/test_generation/test_stacks.py`,
  `test-studio-steps.test.ts`, `test-generation-store-analyze.test.ts`.
