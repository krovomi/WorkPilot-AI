# F165 · Train de release et Snapshots d'environnement ne connaissaient que Node, Python, .NET et Rust

- **Sévérité** moyenne · **trouvé par** le lot 6 de la charte UI (2026-11-08), en reprenant les
  vues du groupe Planification.
- **Preuve** (avant) : `_discover_services` ne cherchait que quatre manifestes ; `_replay_payload`
  écrivait `setup_20.x` et `python3` en dur ; `EnvSnapshotView` lisait `snapshots.find` sans
  garde.
- **Correction** : `release_coordinator/manifests.py`, `analysis/env_stacks.py`,
  `runners/env_snapshot_runner.py`, `stores/env-snapshot-store.ts` ; tests
  `tests/test_planning_polyglot.py`.
