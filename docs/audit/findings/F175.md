# F175 · L'URL du webhook Team Bot vivait en clair dans le localStorage du renderer

- **Sévérité** moyenne · **trouvé** pendant la revue de la charte UI (2026-11-08), confirmé au tri du
  2026-11-09 (develop `ea5db86`).
- **Preuve** (avant) : `persist(…, { name: "workpilot-team-bot" })` sur le store qui contient
  `webhook_url` ; `teamBotSend(config, payload)` et `teamBotTest(config)` envoyaient l'URL au main,
  qui la passait au runner dans `--payload <json>`.
- **Correction** : `main/team-bot-config.ts` (lecture, masque, sauvegarde chiffrée, champs validés),
  canaux `teamBot:getConfig` et `teamBot:saveConfig`, `teamBot:send` / `teamBot:test` sans URL,
  `--payload -` lu sur stdin, migration unique depuis l'ancien localStorage.
