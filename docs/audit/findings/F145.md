# F145 · 955 classes de couleur lisaient des variables CSS qu'aucun thème ne définit

- **Sévérité** moyenne · **trouvé par** l'audit d'harmonisation de l'interface demandé par Leub
  (2026-11-02).
- **Preuve** (avant) : 18 noms (`--text-secondary` ×140, `--color-text-muted` ×90,
  `--color-text-primary` ×73, `--bg-secondary` ×61...) lus par 635 classes dans 24 fichiers, et
  définis ni dans `styles/globals.css` ni ailleurs dans le renderer ; puis 320 classes de plus
  dans 23 fichiers (Pipeline Generator, Agent Coach...) écrites sous la forme courte Tailwind v4
  `text-(--text-secondary)`, que la première version du test ne lisait pas.
- **Correction** : remplacement mécanique par les jetons — texte principal → `foreground`,
  secondaire/atténué/tertiaire → `muted-foreground`, fond principal → `background`, secondaire →
  `card`, tertiaire → `muted`, survol → `accent`, bordures → `border`, accent → `primary`.
  `tests/test_renderer_css_vars.py` échoue si une variable lue, sous `var(--x)` ou `-(--x)`,
  n'est définie nulle part.
