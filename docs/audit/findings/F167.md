# F167 · Débogueur d'agent en écran noir, erreurs JSON brutes dans l'historique et le replay

- **Sévérité** basse · **trouvé par** le lot 8 de la charte UI (2026-11-08), en reprenant les
  vues de l'espace de travail.
- **Preuve** (avant) : `set({ sessions })` avec `sessions` indéfini, puis `sessions.length` au
  rendu ; `await res.json()` sans vérifier le type de la réponse.
- **Correction** : `stores/agent-debugger-store.ts`, `stores/agent-replay-store.ts`,
  `components/SessionHistory.tsx`.
