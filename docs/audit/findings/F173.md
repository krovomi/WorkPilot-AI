# F173 · Hors de l'app installée, les runners n'atteignaient pas src.connectors (Mistral, DeepSeek, Grok, Jira, Azure DevOps)

- **Sévérité** haute · **trouvé** au tri du 2026-11-09 (develop `ea5db86`).
- **Preuve** (avant) : `core/oneshot.py` importe `src.connectors.llm_config` pour Mistral, DeepSeek
  et Grok. `pythonRunnerEnv` (`apps/frontend/src/main/utils/python-runner-env.ts`) et
  `oneshot-llm.ts` ne donnent que le backend comme chemin, et `runners/*.py` n'ajoutent que le
  backend à `sys.path`. Avec `PYTHONPATH=apps/backend`, `python -P -c "import src.connectors"`
  échoue. `deploy/Dockerfile.server` et `.dockerignore` n'incluaient pas `src/`.
- **Correction** : `foundation/connectors_path.py` (`ensure_connectors_on_path`), appelé en tête de
  `core/__init__.py` ; `COPY src /app/src` dans l'image serveur.
- **Test** : `tests/test_connectors_path.py` lance un Python qui n'a que le backend sur son chemin
  et importe `src.connectors.llm_config` après `import core`.
