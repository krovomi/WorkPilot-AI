# F171 · La release lancée par le tag échouait sur les quatre plateformes, electron-builder publiait lui-même

- **Sévérité** haute · **trouvé** à la publication de la 1.4.0 (2026-11-08), run 42504434902.
- **Preuve** (avant) : `pnpm run package:mac -- --arm64` sans `--publish`, sur l'évènement
  `push` du tag `v1.4.0` ; electron-builder appelle `POST /repos/krovomi/WorkPilot-AI/releases` et
  reçoit 403 sur macOS Intel, macOS Apple Silicon, Windows et Linux. Les versions 1.3.3 et 1.3.4
  étaient parties par `workflow_dispatch` sur `main`, sans référence de tag, donc sans publication
  automatique.
- **Correction** : `--publish never` sur les quatre étapes `Package …` de `release.yml` ;
  `tests/test_release_packaging_publish.py` échoue si une étape de packaging l'oublie.
- **Contournement pour la 1.4.0** : release relancée par `workflow_dispatch` sur `main` avec
  `version=1.4.0`.
