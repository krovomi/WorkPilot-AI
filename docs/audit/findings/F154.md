# F154 · Une règle CSS globale écrasait toutes les couleurs de bordure

- **Sévérité** moyenne · **trouvé par** la revue des onglets du détail d'une tâche demandée par
  Leub (2026-11-03) : « pourquoi j'ai une ligne sous les onglets ? ».
- **Preuve** (avant) : dans le panneau, l'onglet actif avait `border-b-2 border-transparent
  data-[state=active]:border-primary`, mais son style calculé donnait `2px solid rgb(35, 35, 35)`
  (le `--border` du thème sombre) pour tous les onglets, actif compris. Cause : la règle
  `* { border-color: var(--border); }` hors couche, qui l'emporte sur `@layer utilities`.
- **Correction** : la règle passe dans `@layer base`. Les onglets du panneau sont regroupés dans
  `TaskDetailTabs.tsx` (rail unique, onglet actif souligné de 3 px à la couleur primaire du thème,
  fond `primary/15`, défilement horizontal).
- **Vérification** : captures avant/après du Kanban, des réglages et du détail d'une tâche en
  clair et sombre ; seules les bordures qui demandaient une couleur changent.
