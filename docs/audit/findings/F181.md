# F181 · Le menu de gauche comptait 61 entrées et la palette n'en trouvait que 21

- **Sévérité** moyenne · signalé par Leub le 2026-11-09 : « Je trouve le menu de gauche trop
  chargé […] Je trouve qu'on s'y perd facilement ». Il a retenu les trois lots proposés.
- **Preuve** (avant, capture du menu en français, fenêtre de 1000 px) : 61 entrées dont 20 dans
  la Boîte à outils ; zone de navigation de 420 px, panneau CLI de 320 px ; « Espace de tra… »,
  « Tableau … », « Contrôle de … » tronqués ; `CommandPalette.tsx` naviguait vers 21 vues par des
  commandes `go_*`.
- **Correction** (lot 1) : `sidebar/nav-model.ts` porte les groupes et les entrées ; la barre
  publie les pages qu'elle montre (`sidebar/nav-index.ts`) et la palette les offre toutes, onglets
  des hubs compris, trouvées par nom, groupe ou mot-clé (`navigation:keywords`), accents ignorés,
  les récentes d'abord ; un outil qui est un dialogue s'ouvre comme depuis le menu
  (`sidebar/nav-actions.ts`). Le champ « Rechercher », `/` et Ctrl+K ouvrent la palette.
  « Outils CLI » devient une pastille (`sidebar/CliToolsChip.tsx`). Les lignes perdent le
  raccourci (dans l'infobulle) et la poignée (au survol), les en-têtes de groupe deviennent de
  simples titres et les noms longs sont raccourcis.
- **Vérification** : `cd apps/frontend && pnpm test -- CommandPalette sidebar`.
