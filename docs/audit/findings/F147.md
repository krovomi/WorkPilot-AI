# F147 · Chaque vue dessinait son propre en-tête et son propre état vide

- **Sévérité** basse · **trouvé par** l'audit d'harmonisation de l'interface demandé par Leub
  (2026-11-02).
- **Preuve** (avant) : 25 vues (Flaky Tests, CI/CD Triggers, Documentation, Historique des sessions,
  Tableau de bord, Estimation des coûts, Administration, Live Companion, Browser Agent, Code
  Migration, Spec Approval, Architecture, Performance, Pipeline Generator, Self-Healing,
  Context Mesh, Dette technique, Refactoring, Traduction inter-langages, RepoBench, Changelog,
  Marketplace de plugins et MCP, Outils des agents, Revue de code) écrivaient leur titre à la
  main avec onze styles différents ; six états vides (issues GitHub et GitLab, PR GitHub, API
  Explorer, aperçu mobile) avaient leur propre mise en page.
- **Correction** : `components/ui/page-header.tsx` (variante `bar` en bandeau, `inline` pour
  les vues qui défilent d'un bloc) et `components/ui/empty-state.tsx`. L'icône de chaque vue
  reprend celle de la barre latérale.
- **Garde-fou** : `tests/test_renderer_page_header.py` refuse un `<h1>` hors de
  `PageHeader`, sauf les écrans plein cadre listés.
