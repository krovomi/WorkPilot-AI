# F168 · Trente analyses échouaient avec « Python environment not ready » avant la première tâche

- **Sévérité** haute · **trouvé par** la capture d'écran de Leub sur le Détecteur de dérive
  (2026-11-07).
- **Preuve** (avant) : `doc-drift-handlers.ts` lisait `pythonEnvManager.getPythonPath()`, `null`
  tant que `initialize()` n'avait pas été appelé ; même motif dans 29 autres handlers.
- **Correction** : `main/utils/ensure-python.ts`, appliqué à tous ces handlers ; tests
  `main/utils/__tests__/ensure-python.test.ts`.
- **Reste** : `RefactoringView.tsx`, `CodeReview.tsx`, `SessionHistory.tsx` appellent encore une URL
  relative `/api/...` depuis le renderer.
