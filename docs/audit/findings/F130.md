# F130 · Rien n'empêchait un fichier source de dépasser 2 000 lignes, ni d'y grossir encore

- **Sévérité** moyenne · **trouvé par le plan du 29 octobre (A2)** · **atténué par le lot N8**
- **Preuve** (avant) : 22 fichiers suivis de plus de 2 000 lignes dans `apps/` (16 frontend,
  6 backend), dont `usage-monitor.ts` 4 637, `worktree-handlers.ts` 3 629, `core/client.py`
  3 214 ; `AGENTS.md` demandait déjà de ne pas les ouvrir en entier, mais rien ne les empêchait
  de grossir.
- **Correction** :
  - `scripts/quality_baselines.py` compte les lignes de chaque fichier source suivi
    (`apps/backend`, `src`, `apps/frontend`) ; au-delà de `LARGE_FILE` (2 000), le fichier a un
    plafond dans `tests/baselines/file-size.json`, à son compte du 30 octobre 2026. Un fichier
    qui grossit, ou un nouveau fichier au-delà de 2 000 lignes, est refusé ; une découpe abaisse
    le plafond (`update`, qui ne monte jamais).
  - `worktree-handlers.ts` ne garde que l'état, la liste, l'abandon, l'ouverture dans un IDE ou
    un terminal, l'analyse d'impact et la synchronisation (1 216 lignes) ; il enregistre les
    autres groupes : `worktree-diff-handlers.ts` (diff), `worktree-merge-handlers.ts` (fusion
    et aperçu), `worktree-file-handlers.ts` (lecture, écriture, suppression),
    `worktree-create-pr-handlers.ts` (PR), `worktree-visual-proof-handlers.ts` (preuve
    visuelle) ; les fonctions partagées vivent dans `worktree-handler-utils.ts`. Le code des
    handlers est déplacé tel quel.
  - `execution-handlers.ts` (3 092 → 506 lignes) garde le démarrage, la reprise de session,
    l'arrêt, l'état, le plan et la pause ; il enregistre `execution-review-handlers.ts`,
    `execution-status-handlers.ts`, `execution-resume-handlers.ts` et
    `execution-recovery-handlers.ts`, qui reçoivent `ExecutionHandlerContext` (gestionnaire
    d'agents, fenêtre principale) au lieu de la fermeture qui les englobait ; les fonctions
    partagées vivent dans `execution-utils.ts`.
- **Reste** : les 20 fichiers plafonnés. Le plafond arrête la croissance, la découpe se fait
  fichier par fichier.
- **Garde-fou** : `tests/test_quality_baselines.py` (un fichier au-delà de son plafond, un
  nouveau gros fichier refusé), le hook pre-push (`quality:baselines`).
