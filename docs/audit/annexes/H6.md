# H6 — Moteur recommandé par type de carte, appris du banc (IA3)

**Fait.** Le banc de rejeu ([G10](G10.md)) disait quel moteur résout le travail du projet, toutes
cartes confondues. Chaque record garde maintenant le type de sa carte (`bug_fix`, `feature`…), et
`results.json` recommande par type le moteur le moins cher parmi ceux à dix points ou moins du
meilleur taux, sur au moins trois cartes du type et au moins la moitié résolue ; sous `"*"`, la même
règle sur toutes les cartes. L'étape moteur d'une carte propose cette recommandation avec ses
preuves (taux, cartes, coût moyen) et un bouton pour l'utiliser ; la vue du banc les liste. Le
routeur de modèles juge un modèle sur les cartes du type de la tâche quand il y en a assez.

Rien ne change le moteur d'une carte sans un clic de la personne. Un type sans assez de preuves n'a
pas de recommandation propre, et la carte le dit en se rabattant sur toutes les cartes.

Justification : [`repo-bench.md`](../../architecture/repo-bench.md#le-moteur-recommandé-par-type-de-carte).

Vérification : `pytest tests/bench tests/model_router -q` ; `cd apps/frontend && pnpm test --
BenchRecommendation RepoBenchView`.
