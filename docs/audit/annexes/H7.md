# H7 — Revue en brouillon des PR ouvertes par d'autres (IA7)

**Fait.** Les automatisations ([G6](G6.md)) ont un quatrième déclencheur, `pr_opened` : une PR
ouverte après la règle par quelqu'un d'autre que la personne (ni elle, ni un bot), éventuellement
vers une seule branche de base. La règle ne crée pas de carte : elle lance la revue IA de GitHub PRs
([G1](G1.md)), avec le moteur de cette page, et la garde en brouillon. Le runner `review-pr` tourne
sans `--auto-post`, personne n'est assigné, et la revue attend dans GitHub PRs que la personne la
publie, la modifie ou l'écarte.

Une revue par PR : une PR déjà relue, à la main ou par une autre règle, est écartée, et deux revues
de la même PR ne tournent jamais en même temps. Le plafond du jour compte les revues (3 par
défaut). Une revue qui n'a pas pu démarrer est retentée au passage suivant et écrite une seule fois
au journal. Une PR en brouillon attend d'être prête. Si GitHub ne dit pas à qui appartient le jeton,
la source échoue plutôt que de relire le travail de la personne. Rien du texte de la PR ne passe par
la règle : le relecteur le lit lui-même, comme contenu non fiable.

Justification : [`automations.md`](../../architecture/automations.md#une-pr-ouverte-par-quelquun-dautre--une-revue-en-brouillon).

Vérification : `cd apps/frontend && pnpm test -- automations pr-draft-review AutomationsIntegration`.
