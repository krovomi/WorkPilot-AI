- **Les captures d'une tâche sur le serveur d'équipe et le téléphone** : l'app mobile montre, sur une carte du serveur, chaque écran avant et après tel que sa PR le montre, avec les types de données remplacés par des faux ; en mode `CAPTURES_PUBLISH=review`, une personne qui relit les publie ou les retire du téléphone, et le serveur met la PR à jour avec son jeton de forge. Seules les copies publiables quittent le clone du serveur. Ce qui est traité et combien de temps, pour le registre RGPD : `docs/pr-captures-data.md`.
