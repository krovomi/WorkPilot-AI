section: ✨ Nouveautés

- **Moteur de « Proposer le sprint »** : à partir de la capacité du sprint (sa vélocité), des règles classent le backlog (priorité, bugs, ce qu'une tâche débloque, but du sprint, âge) et ajoutent d'abord ce qu'une tâche attend ; le modèle du provider choisi compose le sprint parmi les mieux classées et explique chaque choix dans la langue de l'app, puis les règles vérifient que la capacité tient. Sans modèle, les règles proposent seules. Le modèle ne lit que le titre, le début de la description, la priorité, le type, les points, les étiquettes et les dépendances. L'affichage dans la vue « Planifier » arrive avec le lot suivant.
