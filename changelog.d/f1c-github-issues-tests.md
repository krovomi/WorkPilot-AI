- **Les handlers IPC GitHub des issues sont testés contre un GitHub simulé** (lot F1c de la couverture à 100 %) : test de connexion, liste des dépôts, pages d'issues reconstituées sans les pull requests, recherche, issue et commentaires, analyse d'une issue en tâche sur un vrai dossier de projet, spec créée depuis une issue et utilitaires (configuration du projet, jeton de gh, appel d'API).
