- **Ajout rapide du Kanban : la description tapée sous le titre est gardée.** Un titre suivi de
  Maj+Entrée puis d'une description donne une seule carte (titre = première ligne) au lieu d'une
  carte par ligne ; seule une liste collée est découpée par défaut. La pré-analyse lit aussi une
  description en texte riche sans ses balises et y ajoute les réponses en HTML.
